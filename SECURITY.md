# Segurança

Este projeto automatiza um sistema de acesso restrito. Use somente contas e
dados para os quais você tenha autorização formal.

Nunca publique:

- usuário ou senha do SISP/REDS;
- tokens do Instagram/Facebook Graph;
- chaves do Gemini ou Cloudinary;
- PDFs, fotos ou dados pessoais extraídos de ocorrências.

Os arquivos reais de configuração são ignorados pelo Git. Use os arquivos
`.example.json` como modelo e mantenha os valores operacionais apenas na sua
máquina.

Se um segredo for publicado por engano, revogue-o imediatamente e remova-o de
todo o histórico Git antes de continuar.
